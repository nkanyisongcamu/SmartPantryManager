3. INTRODUCTION
Smart Pantry Manager is a Java Android application designed to reduce food waste by helping users track ingredients already available in their pantry. The application focuses on strict recipe matching: a recipe is suggested only when every required ingredient is available in the pantry. This removes the need for the user to buy an additional missing ingredient.
